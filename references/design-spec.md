# 无界实验室设计规范

## 1. 品牌核心
### 1.1 品牌定位
无界实验室面向青少年群体。设计语言需要同时传递**科学专业性**与**青少年友好感**：既要有实验室的严谨，也要有探索未知的轻盈与活力。

### 1.2 品牌关键词
年轻、科学、探索、友好、科技前沿
---
## 2. 色彩系统
### 2.1 品牌主色
品牌采用**双主色**体系：科技蓝作为信任锚点，荧光青作为活力 accent。
**主色蓝**
主色蓝是 `#0083FE`，一枚饱和度较高、偏冷调的科技蓝。它用于主按钮、关键链接、聚焦态边框以及导航 CTA，是品牌识别度最高的颜色。
完整色阶：
- 50 `#E6F3FF` — 最浅背景高光
- 100 `#CCE7FF` — 轻微蓝色背景
- 200 `#99CFFF` — 蓝色背景层
- 300 `#66B7FF` — 浅蓝色强调
- 400 `#339FFF` — 中浅蓝色，深色模式主色
- 500 `#0083FE` — 品牌主色蓝
- 600 `#0069CB` — 悬浮态蓝色
- 700 `#004F98` — 深蓝色
- 800 `#003566` — 重色背景
- 900 `#001A33` — 最深蓝色

**荧光青**
荧光青是 `#00FFF0`，作为次级强调色与活力标记。它承担次级按钮、悬浮反馈、强调图标、渐变终点等角色。在浅色背景上提供高能量但不刺眼的点缀。
完整色阶：
- 50 `#E6FFFE`
- 100 `#CCFFFD`
- 200 `#99FFFB`
- 300 `#66FFF9`
- 400 `#33FFF7` — 深色模式青色
- 500 `#00FFF0` — 品牌荧光青
- 600 `#00CCC0` — 悬浮态青色
- 700 `#009990`
- 800 `#006660`
- 900 `#003330`

### 2.2 中性色
中性色采用 9 阶灰度，从 `#F7F7F7` 到 `#1A1A1A`。
- 50 `#F7F7F7` — 表面容器背景
- 100 `#ECECEC` — 次级表面、悬浮背景
- 200 `#D9D9D9` — 边框、分隔线
- 300 `#B3B3B3` — 浅灰装饰
- 400 `#999999` — 弱化信息
- 500 `#808080` — 辅助说明文字
- 600 `#666666` — 次级正文
- 700 `#4D4D4D` — 深色模式边框
- 800 `#333333` — 正文色
- 900 `#1A1A1A` — 深色背景、标题重色

### 2.3 语义色
- 成功 `#43A047`
- 警告 `#FFB300`
- 错误 `#E53935`

浅色模式下：
- `--primary` = `#0083FE`
- `--primary-foreground` = `#FFFFFF`
- `--secondary` = `#00FFF0`
- `--secondary-foreground` = `#1A1A1A`
- `--accent` = `#00FFF0`
- `--accent-foreground` = `#1A1A1A`
- `--accent-hover` = `#00CCC0`
- `--background` = `#FFFFFF`
- `--foreground` = `#333333`
- `--muted` = `#ECECEC`
- `--muted-foreground` = `#808080`
- `--border` = `#D9D9D9`
- `--ring` = `#0083FE`
- `--surface` = `#FFFFFF`
- `--surface-container` = `#F7F7F7`
- `--surface-container-low` = `#ECECEC`

### 2.5 深色模式
深色模式将背景反转为 `#1A1A1A`，主色提亮为 `#339FFF`，青色提亮为 `#33FFF7`。
- `--background` = `#1A1A1A`
- `--foreground` = `#F7F7F7`
- `--muted` = `#333333`
- `--muted-foreground` = `#999999`
- `--border` = `#4D4D4D`
- `--primary` = `#339FFF`
- `--primary-foreground` = `#1A1A1A`
- `--secondary` = `#33FFF7`
- `--secondary-foreground` = `#1A1A1A`
- `--surface` = `#333333`
- `--surface-container` = `#333333`
- `--surface-container-low` = `#1A1A1A`

### 2.6 色彩使用原则
- 白色画布占据主导，品牌色作为聚焦锚点出现
- 青色像荧光标记一样用于悬浮、次要强调和渐变终点
- 渐变：从 `#0083FE` 到 `#00FFF0` 的线性渐变，用于 Hero 背景、强调区块
- 阴影统一使用深海蓝 `#003366` 作为色相，保持柔和漫射
- 深色模式保持可访问性，科技氛围更强烈

## 3. 字体系统
### 3.1 字体家族
- 中文：思源黑体
- 英文/数字：`Helvetica`
- 等宽：`SF Mono / Menlo / Monaco / Consolas`等宽字体仅用于代码或数据标注场景。

### 3.2 字号层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Display | 56px | 700 | 1.1 | 首页大标题 |
| H1 | 40px | 700 | 1.2 | 页面主标题 |
| H2 | 32px | 600 | 1.25 | 区块标题 |
| H3 | 24px | 600 | 1.3 | 卡片标题 |
| H4 | 20px | 600 | 1.4 | 小标题 |
| Lead | 18px | 400 | 1.7 | 引导段落 |
| Body | 16px | 400 | 1.6 | 正文 |
| Caption | 12px | 400 | 1.5 | 辅助说明、徽章 |
| Eyebrow | 11px | 600 | 1.4 | 章节标签，全大写，字间距 0.08em |
| Mono | 14px | 400 | 1.6 | 代码、数据 |

### 3.3 字体使用原则

- Display 与 H1 使用 700 建立标题冲击力
- H2-H4 使用 600 保持清晰但不沉重
- 正文 400 确保长文可读
- 标题 letter-spacing 略收紧，eyebrow 字间距放宽
- 不使用全大写标题作为品牌音量，靠色彩与版式建立能量

## 4. 间距系统

### 4.1 间距 Token

以 4px 为基底：

- `space-1` = 4px
- `space-2` = 8px
- `space-3` = 12px
- `space-4` = 16px
- `space-5` = 20px
- `space-6` = 24px
- `space-7` = 32px
- `space-8` = 48px

### 4.2 尺寸 Token

- `--size-button-height` = 44px
- `--size-input-height` = 44px
- `--nav-height` = 64px
- `--max-content` = 1200px
- `--gutter` = 16px

### 4.3 间距使用原则

- 页面内容最大宽度 1200px，水平 gutter 16px
- 卡片默认内边距 24px
- 按钮、输入框默认高度 44px
- 小号按钮 32px，大号按钮 52px
- 组件之间优先使用 space-4 到 space-6

## 5. 圆角系统

- `--radius-sm` = 4px — 小号按钮、紧凑控件
- `--radius-md` = 8px — 默认控件圆角：按钮、输入框、导航链接、卡片图标容器
- `--radius-lg` = 16px — 大卡片、模态容器
- `--radius-xl` = 24px — 主要卡片
- `--radius-full` = 9999px — 仅用于 Badge，形成 pill 标签
